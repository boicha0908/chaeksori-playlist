책 소개를 읽고 맞춤 추천하기
교보문고 검색 결과를 열어 책 소개를 복사한 뒤 아래 칸에 붙여넣어 주세요. 서버가 AI로 곡 후보를 고르고 YouTube 검색 결과를 확인합니다. 책 소개를 자동으로 가져오는 교보문고 공개 API는 확인되지 않아, 소개 복사는 직접 해야 해요.

처음 실행할 때 준비할 것
  1. 폴더 안의 .env.example을 복사해 .env라는 이름으로 저장합니다.
  2. .env에 Gemini API 키와 YouTube Data API 키를 입력합니다. 키는 이 파일과 서버에만 두고 다른 사람에게 보내지 마세요.
  3. start-local.bat을 실행한 뒤, 브라우저에서 http://127.0.0.1:5174를 엽니다. index.html을 직접 열면 API 추천은 작동하지 않아요.

Gemini 무료 사용량에는 모델별 요청 제한이 있고, 무료 입력은 Google 제품 개선에 사용될 수 있어요. YouTube에서 제목과 아티스트가 함께 검색되는 곡만 표시하지만, 영상이 공식 업로드인지까지 자동으로 보증하지는 않으니 결과를 직접 확인해 주세요.

AI가 책 소개에서 분위기와 주제를 찾고, 실제 YouTube 검색 결과와 대조해 곡을 골라요. 전에 나온 곡은 다시 추천하지 않아요.
